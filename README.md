💡 모든 명령어는 앞에 느낌표(!)를 붙여서 사용합니다.

🔹 !등록 [이터널리턴 닉네임] : 내전 시스템에 내 프로필을 최초 등록합니다.

🔹 !정보 : 내 닉네임, 전적(승/패), 승률, 현재 MMR을 조회합니다.

🔹 !인원 : 등록된 모든 내전 멤버들의 닉네임, 전적을 순서대로 조회합니다.

🔹 !매칭 : 현재 통화방에 입장한 인원 기준으로 MMR 균형에 맞게 팀을 반반 나눕니다

🔹 !명령어 : 현재 보고 계신 봇 사용 설명서를 다시 띄웁니다.
